## Escalation Paths

1. **General Discussions & Questions**: Open a discussion on [GitHub Discussions](https://github.com/cordanaLLM/nucleus/discussions).
2. **Defect Triage & Build Failures**: File an issue via the [GitHub Issue Tracker](https://github.com/cordanaLLM/nucleus/issues).
3. **Architectural & Governance Escalation**: Reach out to the Maintainers Council via `@lusoris` on GitHub Discussions or pull request reviews.
4. **Security Escalation**: For sensitive or security-related matters, contact the security team via [GitHub Security Advisories](https://github.com/cordanaLLM/nucleus/security/advisories/new).

---

## Security Contact

For confidential vulnerability reports, do not open public issues. Refer to [SECURITY.md](SECURITY.md) and report directly through [GitHub Security Advisories](https://github.com/cordanaLLM/nucleus/security/advisories/new).
